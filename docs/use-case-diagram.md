## 👥 Project Actors

| Actor | Description |
| :--- | :--- |
| **Student** | Regular user who browses and interacts with events. |
| **Club** | Organization account that can create and manage events. |
| **Admin** | System moderator responsible for safety and roles. |
| **Security System** | External system that handles authentication via JWT. |
